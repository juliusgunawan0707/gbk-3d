# GBK 3D — Gelora Bung Karno Stadium Replica

Interactive 3D stadium in the browser (three.js r128): numbered ticket sections, a recreated
Indonesia 2-0 Saudi Arabia match (2026 World Cup qualifier), ~36,000 animated supporters,
day/night cycle and multiple camera presets. Single self-contained `index.html`, no CDN.

Fan-made, non-commercial demo. Not affiliated with PSSI, AFC, FIFA or any club/sponsor;
sponsor boards are fictional. Player names are used only to reference the real fixture.
